**Таблица страниц** (англ. _Page Table_) — это структура данных, используемая в архитектуре современных процессоров для реализации **виртуальной памяти**. Она служит для отображения (маппинга) **виртуальных адресов** в **физические адреса**.

###  Зачем нужна таблица страниц:

1. **Изоляция процессов** — каждый процесс имеет своё виртуальное адресное пространство.
2. **Защита памяти** — один процесс не может напрямую обращаться к памяти другого.
3. **Эффективное использование памяти** — позволяет использовать только реально нужные страницы.
4. **Виртуализация и подкачка (paging)** — части программы могут быть выгружены на диск и загружены по мере необходимости.

### 🔧 Как это работает:

1. Программа обращается к **виртуальному адресу**.
2. Процессор использует таблицу страниц, чтобы найти **соответствующий физический адрес**.
3. Этот механизм управляется **MMU** (Memory Management Unit — блок управления памятью).

### 🧱 Структура (на примере x86 с 32-битной адресацией):

При включённой **постраничной трансляции (paging)**, виртуальный адрес делится на части:

- **Каталог страниц (Page Directory)** — верхний уровень (10 бит).
- **Таблица страниц (Page Table)** — второй уровень (ещё 10 бит).
- **Смещение в странице (Offset)** — 12 бит (так как размер страницы — 4 КБ = 2¹² байт).

Таким образом, 32-битный виртуальный адрес разбивается на:

```less
[10 бит] [10 бит] [12 бит]
   |        |        |
   |        |        └─ Смещение внутри страницы
   |        └────────── Индекс в таблице страниц
   └─────────────────── Индекс в каталоге страниц

```

### Типы таблиц в x86-64 (64-бит):

В 64-битной архитектуре используются **4 уровня** таблиц:

- PML4 (Page Map Level 4)
    
- PDPT (Page Directory Pointer Table)
    
- Page Directory
    
- Page Table
    

---

### Каждая запись (PTE — Page Table Entry) содержит:

- Физический адрес страницы
    
- Бит присутствия (Present)
    
- Флаг доступности (только чтение, чтение/запись)
    
- Флаг пользовательский/привилегированный (Ring 0/Ring 3)
    
- Бит кэширования, доступности и другие
