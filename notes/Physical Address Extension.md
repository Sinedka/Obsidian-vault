**Physical Address Extension (PAE)** — это технология, реализованная в процессорах x86, которая позволяет использовать **более 4 ГБ физической оперативной памяти** в 32-битных системах.
### 🔍 Кратко:

- Без PAE: 32-битный процессор может адресовать максимум **4 ГБ** физической памяти (2³²).
- С PAE: адреса расширяются до **36 бит**, что позволяет адресовать до **64 ГБ** физической памяти (2³⁶).
- Виртуальные адреса по-прежнему **32-битные**, но физические адреса — **расширенные**.
### 📌 Где используется:

- В 32-битных версиях Windows (например, Windows Server 2003, XP PAE)
- В Linux (`CONFIG_X86_PAE` в ядре)
- В гипервизорах и виртуализации
- В современных BIOS/UEFI и операционных системах как часть перехода к 64-битным системам

---

### ⚙️ Как работает:

При включённом PAE:

- **Каждая страница всё ещё 4 КБ**
- Таблицы страниц переходят от **2-уровневой** структуры к **3-уровневой**:
    - Page Directory Pointer Table (PDPT) — новый верхний уровень
    - Page Directory
    - Page Table
- Каждая запись таблицы страниц становится **64-битной**, чтобы уместить 36-битные физические адреса и дополнительные флаги.

---

### 📊 Пример:

| Адрес           | Возможности                |
| --------------- | -------------------------- |
| 32-бит без PAE  | до 4 ГБ физической памяти  |
| 32-бит с PAE    | до 64 ГБ физической памяти |
| 64-бит (x86_64) | теоретически до 256 ТБ+    |
