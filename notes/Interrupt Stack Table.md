**IST (Interrupt Stack Table)** — это механизм в 64-битной архитектуре **x86_64**, позволяющий задать отдельные стеки для определённых обработчиков прерываний. Он используется вместе с **TSS (Task State Segment)** и предоставляет **альтернативные стеки** при возникновении прерываний.

## 📘 Зачем нужен IST?

В обычной ситуации при прерывании процессор сохраняет контекст на текущем стеке. Но если:
- стек повреждён (например, **stack overflow**),
- стек используется атакующим (например, **stack smashing**),
- происходит **double fault** (двойное исключение),
то дальнейшее использование обычного стека может привести к краху системы. В этих случаях процессор может переключиться на **альтернативный стек**, указанный в IST.

## 🔧 Как работает IST

- В **TSS** (Task State Segment) в 64-битном режиме есть массив из **7 записей IST**.
- В дескрипторе прерывания в IDT есть поле `IST`, которое указывает индекс в этом массиве.
- Если `IST ≠ 0`, при срабатывании прерывания процессор:
    - **переключается на стек**, указанный в соответствующем поле IST в TSS;
    - продолжает выполнение обработчика уже на **альтернативном безопасном стеке**.

## 📂 Пример: структура TSS с IST

```c
struct TSS64 {
    uint32_t reserved0;
    uint64_t rsp0;  // Стек для кольца 0 (обычный)
    uint64_t rsp1;
    uint64_t rsp2;
    uint64_t reserved1;
    uint64_t ist1;  // Альтернативный стек 1
    uint64_t ist2;
    uint64_t ist3;
    uint64_t ist4;
    uint64_t ist5;
    uint64_t ist6;
    uint64_t ist7;
    uint64_t reserved2;
    uint16_t reserved3;
    uint16_t iopb_offset;
};
```

## 🛠 Пример использования IST

Допустим, ты хочешь, чтобы `#DF (Double Fault)` использовал безопасный стек:

1. Выделяешь отдельный стек в памяти.
2. Прописываешь его в `ist1` в TSS.
3. В IDT-дескрипторе для вектора `#DF` (обычно 8) выставляешь `IST = 1`.
## ⚠️ Важные моменты

- `IST = 0` означает: **не использовать альтернативный стек**, применять текущий стек.
- Использование IST обязательно для некоторых критичных исключений: **#DF**, **NMI**, **#MC** (Machine Check), чтобы избежать повторных сбоев.
- Стек в IST должен быть заранее инициализирован (например, выделен через `alloc_page` и установлен указатель в TSS).
